# 🏨 Grand Horizon Hotel Website

A responsive, single-page website designed for a luxury hotel. This project demonstrates modern UI design principles, including CSS Grid layouts, smooth navigation, and JavaScript-based error handling.

![Project Screenshot](placeholder-image-url-here-if-you-have-one)

## 🚀 Features

### Core Structure

- **Single Page Navigation:** Smooth scrolling between Home, Gallery, Menu, and Contact sections without page reloads.
- **Responsive Design:** Fully adapts to mobile, tablet, and desktop screens using Media Queries.

### 🎨 Visual & UI

- **Luxury Aesthetic:** Uses a Gold (`#c9a96e`) and Dark Grey (`#222`) color palette.
- **Custom Scrollbar:** A WebKit-styled gold scrollbar replaces the default browser bar.
- **CSS Grid Gallery:** A responsive image grid that auto-adjusts columns based on screen width.

### ⚡ Smart Functionality

- **Auto-Fallback Images:** Custom JavaScript detects broken image URLs and instantly replaces them with a placeholder containing the correct label (e.g., "Swimming Pool").
- **Interactive Menu:** Indian cuisine menu with visually distinct cards and pricing.

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic Tags like `<nav>`, `<section>`, `<footer>`)
- **Styling:** CSS3 (Flexbox, Grid, Linear Gradients, WebKit Scrollbar)
- **Logic:** Vanilla JavaScript (Event Listeners for Image Error Handling)
